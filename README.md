1. Проект создан для контроля задач, чтобы не пропустить дедлайны, что упрощает работу
2. Задания со звёздочкой выполнены все, кроме правил повторения
3. Проект нужно запускать с адреса http://localhost:7540/ и форму авторизации http://localhost:7540/login.html,
Чтобы запустить тесты нужно записать пароль с помощью команды в PowerShell $env:TODO_PASSWORD="ВАШ_ПАРОЛЬ" 
И перейдя на форму авторизацию (http://localhost:7540/login.html) ввести пароль, который вы указали в команде
после этого взять токен (F12 - Storage или Хранилище - куки - имя token нужно взять значение) и вставить его в файл 
tests/settings.go в token = ''
4. Чтобы запустить проект через докер нужно 
    1. Запустить Docker desktop на своём компьютере
    2. Запустить в папке с проектом PowerShell и ввести команду docker build -t scheduler .
    3. Там же ввести команду docker run --name scheduler -p 7540:7540 -v "ПУТЬ_К_ПРОЕКТУ:/data" -e TODO_PASSWORD=ВАШ_ПАРОЛЬ scheduler
